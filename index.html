מאבק בטרור החקלאי בישראל

מעבר מאבטחה פסיבית לשיטור מנבא (Predictive Policing) מבוסס Edge AI.

הפשיעה החקלאית (גניבות בקר, השחתת ציוד, הצתות מכוונות) מסבה נזק של מיליונים ומהווה איום אסטרטגי. התמודדות משמר הגבול מוגבלת עקב השטחים העצומים, וחקלאים סובלים מ"עייפות התראות" ממצלמות אבטחה טיפשות שמתריעות על כל כלב שוטה או ענף ברוח.

פלטפורמת דחלילאיי (ScarecrowAI) היא שומר וירטואלי חכם. היא משתמשת במחשוב קצה עצמאי (Off-Grid) כדי לנתח וידאו בשטח ללא תלות בענן. המערכת מזהה אנומליות, מפעילה הרתעה אקטיבית פולימורפית (לייזר ירוק ממוקד וסאונד משתנה), ומשדרת התראות אמת בלבד (SIA DC-09) ישירות למוקדי השמירה ולמכשיר החקלאי.

🧐

עיבוד קצה (Edge AI)

אין צורך באינטרנט מהיר. רשתות ניורונים (YOLO) פועלות על החומרה בשדה, מסווגות אנשים/רכבים ומונעות אזעקות שווא.

🔦

הרתעה פולימורפית

שילוב לייזר ירוק (532nm) ואודיו דינמי (סירנות, נביחות) המשתנה לפי סוג האיום כדי למנוע התרגלות (Habituation).

📈

חקר אירועים (RCA)

ניתוח סיבות שורש של היסטוריית הפשיעה. הפקת מפות חום וזיהוי דפוסים באמצעות LLMs לתכנון כוחות יעיל.

ניתוח מתחרים וכשלי שוק

הפערים בפתרונות הקיים והיתרון של דחלילאיי בשטח מנותק.

רשתות תקשורת

ZORONET (זורונט) ודומותיה

פתרונות מבוססי רשתות סנסורים ומצלמות אלחוטיות הפרוסות בשטחים רחבים לצורך איסוף נתונים למוקד.

הפער לעומת דחלילאיי:
  • מתבססות לרוב על תקשורת נתונים כבדה לענן (שלא קיימת בשטח).
  • חסרות מערך הרתעה אקטיבית ומשתנה (לייזר/קול). הן פאסיביות.
  • ללא עיבוד Edge AI בקצה העמוד, מה שגורם לעומס התראות סרק.

LiveView Tech (LVT)

עגלות ניטור סולאריות ניידות עם מצלמות תרמיות, תקשורת והרתעה חזותית.

מגבלות:
  • בולטות פיזית אדירה (גנבים לומדים את נקודות העיוורון).
  • עלויות השכרה אסטרונומיות שאינן משתלמות לחקלאי קצה.

Magos Systems

מערכות מכ"ם (Radar) ברזולוציה גבוהה יחד עם מצלמות PTZ שמסתובבות למטרה.

מגבלות:
  • מחיר חומרה יקר מאוד המיועד למתקנים אסטרטגיים.
  • התקנה מסובכת הדורשת מומחיות וכיול רדאר מדויק.

Avigilon / Hikvision

מצלמות אבטחה חכמות (CCTV) מבוססות AI, עם שרתי חקירה והקלטה מקומיים (NVR).

מגבלות:
  • דורשות תשתית תקשורת קווית (LAN) ויציבות חשמל מוחלטת.
  • לא ניתן לפרוס בשדות פתוחים, כרמים ושטחי מרעה מבודדים.

ארכיטקטורת הפתרון

כיצד המערכת עובדת מקצה לקצה - מהשדה ועד לחפ"ק.

📷

1. איסוף וחיישנים בשטח

מצלמת PTZ מוגנת מים (IP67) עם חיישן Starlight / תרמי. פועלת 24/7 מאנרגיה סולארית ועוקבת אחר תנועה בסביבה חשוכה.

🧐

2. סינון אנומליות ו-AI מקומי

מעבד ה-NVIDIA Jetson מקבל את הוידאו. אלגוריתמי YOLOv8 ו-LSTM שואלים: זה טנדר? אדם? עגל? אש? אם זה איום - עוברים לשלב הבא.

🔦

3. הרתעה וגירוש (Polymorphic)

המערכת משתמשת בלייזר ירוק בטיחותי וסירנות המפיקות סאונד רנדומלי מתוך מאגר מקומי כדי להבריח את הפולש באותו רגע.

📡

4. דיווח למוקד ואינטגרציה

שליחת חבילת נתונים קטנה (תמונת Keyframe + קואורדינטות) דרך מודם 4G בתקן SIA DC-09-2026 המאובטח ישירות למוקד השומר החדש / משטרה ולדשבורד ה-React/Mapbox של החקלאי.

💻

הזרמת נתונים (Data Pipeline)

Input: RTSP Stream (Camera)
Process: YOLOv8 TensorRT (NVIDIA Jetson) -> Object == "Human/Truck"
Act: GPIO Relay -> Trigger 532nm Laser & Siren
Output: MQTT / REST API (AWS IoT Core) -> SIA DC-09 XML Alarm

דרישות טכנולוגיה וחומרה

פירוט רכיבי התוכנה והאלקטרוניקה לבניית המערכת.

🛠 מפרט חומרת קצה (Edge)

  • NVIDIA Jetson Orin Nano Super

    לוח פיתוח מבוסס ארכיטקטורת Ampere עם 1024 ליבות CUDA. מפיק 67 TOPS, צורך פחות מ-15 וואט בעבודה. המוח של המערכת.

  • מערכת אנרגיה סולארית (Off-Grid)

    פאנל 100W/150W, בקר טעינה MPPT, וסוללת ליתיום ברזל פוספט (LiFePO4) 12V 50Ah לעמידות בתנאי חוץ ופריקות עמוקות.

  • מצלמת תנאי שטח (PTZ Starlight)

    מצלמת רשת עם רגישות אור גבוהה במיוחד להפקת תמונה צבעונית בחשיכה (או מצלמה תרמית) בתקן אטימות IP67.

  • מקרן לייזר וממסרים

    לייזר ירוק 532nm מסיווג 3B, רמקול חוץ עוצמתי, וממסרי מתח חכמים המופעלים מפיני ה-GPIO של הבקר.

💻 ענן, ממשק ותוכנה

  • Machine Learning / CV

    מודלים של YOLOv8/v11 לזיהוי חפצים, בשילוב רשתות קונבולוציה CNN+LSTM לניתוח אנומליות זמניות ומרחביות בחווה.

  • גילוי מוקדם של הצתות (Early Arson Detection)

    שימוש במודל DetectNet_v2 / ResNet-18 המכווץ באמצעות Pruning לזיהוי להבות ועשן לפני התפשטות השריפה.

  • פרוטוקול תקשורת משטרתי - SIA DC-09

    תקן תקשורת מאובטח עולמי להעברת אזעקות אמת מהשדה למערכות ניהול במוקדים (100 של המשטרה או מוקדי אבטחה פרטיים).

  • מערכת מידע גיאוגרפית (GIS Dashboard)

    פיתוח ב-React.js בשילוב ספריות מפות כגון Leaflet.js עם GeoServer או Mapbox GL JS למיפוי ויזואלי של ההתראות בזמן אמת.

התפלגות התקציב (מבוסס ממוצע)

שיטור מנבא וביסוס אקדמי

ניתוח סיבות שורש (RCA) וזיהוי מגמות בסביבה אגרו-טכנולוגית.

מודל חקר סיבות שורש (Root Cause Analysis - RCA)

מעבר להרתעה המיידית, דחלילאיי מתפקדת כמערכת מודיעין לטווח ארוך (Predictive Policing). המערכת אוספת מטא-דאטה מכל אירוע (שעה, מיקום במפה, סוג איום, מזג אוויר).
שימוש במודלים כמו יערות אקראיים (Random Forest) או Gradient Boosting מאפשר למצוא קורלציות בנתונים - למשל, זיהוי "אזורים חמים" (Hotspots) של גניבות בקר בסופי שבוע. שילוב מודלי שפה גדולים (LLMs) יכול לייצר נרטיב טקסטואלי המסביר לחקלאי מהן נקודות התורפה של החווה.
