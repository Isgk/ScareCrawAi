תקציר מנהלים: פרויקט "דחלילאיי"

מערכת אוטונומית מבוססת בינה מלאכותית להרחקת מזיקים מחקלאות

פרויקט "דחלילאיי" מציע פתרון חדשני לבעיה עתיקת יומין: נזקי חקלאות הנגרמים על ידי ציפורים ומזיקים אחרים. נזקים אלו מוערכים במיליארדי דולרים בשנה ברחבי העולם. המערכת שלנו משלבת ראייה ממוחשבת (Computer Vision) בקצה (Edge AI) כדי לזהות בזמן אמת חדירת מזיקים, לסווג אותם, ולהפעיל אמצעי הרתעה ספציפיים ומשתנים (קול, תנועה, תאורה) כדי למנוע התרגלות (Habituation).

👁

זיהוי מדויק

אלגוריתם AI מזהה את סוג המזיק ומונע הפעלת שווא על בני אדם או חיות משק.

🎯

הרתעה דינמית

שינוי דפוסי פעולה אוטומטי כדי למנוע מהמזיקים להתרגל למערכת.

📈

איסוף נתונים

תיעוד תנועת המזיקים והפקת דוחות לחקלאי לטובת קבלת החלטות.

מחקר שוק ומתחרים

בחינת הפתרונות הקיימים בשוק והכשלים המרכזיים שלהם.

💨

תותחי גז / פצצות קול

הפתרון הנפוץ ביותר כיום. מפיק פיצוצים רועשים במרווחי זמן קבועים.

בעיות מרכזיות:
  • התרגלות מהירה מאוד של הציפורים (מספר ימים).
  • זיהום רעש סביבתי ופגיעה ביישובים סמוכים.
  • פועל בצורה עיוורת גם כשאין מזיקים.
🚁

מערכות לייזר אוטומטיות

מערכות (כמו Agrilaser) הסורקות את השדה בקרני לייזר ירוקות.

בעיות מרכזיות:
  • עלות גבוהה מאוד (אלפי דולרים למערכת).
  • סריקה עיוורת - לא מזהה מטרה, עובד על טיימר.
  • סכנת סינוור לבני אדם / כלים חקלאיים.
🦅

דחלילים סטטיים / עפיפונים

פתרונות ויזואליים דמויי טורפים שמוצבים בשטח.

בעיות מרכזיות:
  • אפקטיביות יורדת לאפס לאחר זמן קצר.
  • דורש הזזה ידנית מתמדת על ידי החקלאי.
  • בלאי גבוה מפגעי מזג אוויר.

היתרון היחסי של דחלילאיי

כיצד המערכת פותרת את כשלי השוק הקיימים.

תגובה מותאמת ואקטיבית

  • ✔
    מניעת התרגלות (Anti-Habituation)

    המערכת משתמשת בלמידת חיזוק או באלגוריתמיקה אקראית כדי לשנות את סוג ההרתעה (קולות עורב, צפצופים, תנועה מכנית) בהתאם לתגובת הציפור בעבר.

  • ✔
    פעולה ממוקדת בלבד

    המערכת "ישנה" עד לזיהוי ודאי של מזיק דרך המצלמה. חוסך באנרגיה (קריטי להפעלה סולארית) ומונע רעש מיותר.

  • ✔
    עלות אל מול תועלת

    שימוש ברכיבי קצה זולים יחסית (Raspberry Pi/Jetson) ומצלמות אבטחה סטנדרטיות, מאפשר פריסה רחבה בעלות שבריר ממערכות לייזר מסחריות.

דרישות טכנולוגיות וחומרה

האמצעים הנדרשים לפיתוח אב הטיפוס.

💻 תוכנה ואלגוריתמיקה

מודל ראייה ממוחשבת (CV) YOLOv8 או MobileNet SSD לזיהוי אובייקטים בזמן אמת על חומרת קצה מוגבלת (Edge AI). שימוש בספריית OpenCV לעיבוד התמונה.
שפת פיתוח (Backend) Python 3.x כשפה המרכזית בבקר הקצה (ניהול החומרה, תקשורת והרצת המודל). שימוש ב-FastAPI לניהול API מקומי.
תקשורת ומסד נתונים פרוטוקול MQTT לדיווח אירועים מהיר. שמירת לוגים מקומית ב-SQLite או סנכרון ל-Firebase/MongoDB בענן.
ממשק משתמש (לוח בקרה) אפליקציית Web פשוטה (React / HTML+JS+Tailwind) להצגת סטטיסטיקות לחקלאי ושליטה מרחוק.

🛠 חומרה וציוד נדרש

🖥
מיקרו-בקר / מחשב קצה Raspberry Pi 4/5 או NVIDIA Jetson Nano (מועדף לביצועי AI גבוהים).
📷
מצלמת רשת / ייעודית מצלמת RPi Camera Module 3 או מצלמת IP חיצונית תומכת ראיית לילה (IR).
📢
אמצעי הרתעה (Actuators) רמקול עוצמתי (Horn Speaker) וכרטיס קול בסיסי להפקת צלילים משתנים. אופציה: פנס לד עוצמתי להבהוב בלילה.
🔋
הזנת מתח סולארית (אופציונלי לאב טיפוס) פאנל סולארי קטן 50W, בקר טעינה וסוללת LiFePo4 לעצמאות בשטח.

תקנים ושמירה על הסביבה (פרויקט ירוק)

אף שבטופס צוין "לא", כדאי לחשוב שוב! פרויקט כזה יכול להיחשב ירוק שכן הוא מפחית זיהום רעש (מופעל רק כשצריך ולא ברצף) ומונע חלופות של פיזור רעלים וכימיקלים נגד מזיקים. שווה לבסס זאת מחקרית.
